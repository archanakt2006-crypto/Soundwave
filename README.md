# 🎵 SoundWave – Music Streaming Web Application

**SoundWave** is a modern music streaming web application developed using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**. It provides users with an interactive platform to explore songs, artists, albums, and playlists through a simple and responsive interface.

## 📌 Project Overview

SoundWave is designed to provide a smooth and engaging music-listening experience. Users can browse music, search for songs and artists, create playlists, and manage their favorite tracks.

The project demonstrates full-stack web development using React.js for the frontend, Node.js and Express.js for the backend, and MongoDB for database management.

## 🚀 Features

* 🎵 Browse and play songs
* 🔍 Search songs, artists, and albums
* 🎤 Explore artists
* 💿 Browse albums
* ❤️ Add songs to favorites
* 📂 Create and manage playlists
* ⏯️ Music player controls
* 👤 User registration and login
* 🔐 Secure authentication
* 📱 Responsive design
* ⚙️ Admin management of songs and artists
